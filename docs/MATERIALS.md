# 材料规则

材料按「大类 + 形态」归组，运行时读取服务端 Item Tags。默认提供 45 类，包括木板、原木、去皮原木、木、去皮木、各类木制形态、石材、砂岩、羊毛、地毯、混凝土、粉末、玻璃、陶瓦、蜡烛和铜制形态等。26.3 的羊毛/混凝土楼梯和台阶也有独立分组。

木板不能替代台阶/楼梯，完整玻璃不能替代玻璃板，羊毛不能替代地毯，混凝土不能替代粉末。未归组物品要求相同 Item。

特殊计费：

- 完整门、床、双层植物只收取一个物品；缺失另一半的结构拒绝导入。
- 双台阶两个台阶；雪层、蜡烛、海泡菜、海龟蛋及成簇花草按实际堆叠数量收费。
- 红石线消耗红石，墙上火把消耗对应火把，作物消耗对应种子/作物种植物品。
- 海带茎、垂泪藤茎、缠怨藤茎、洞穴藤蔓茎和竹笋消耗各自的种植物品；完整高海草只收取一个海草物品，缺失另一半时拒绝导入。霜冰每格消耗一个冰，保留原来的霜冰状态。
- 伸出的普通/黏性活塞只按底座收取一个活塞物品，允许缺少活塞头（包括活塞头在保存选区之外），保留原始伸出状态和朝向。若前方包含方块，必须是类型和朝向一致的完整活塞头；孤立或不匹配的活塞头、移动活塞和移动中的短活塞头拒绝导入。不会自动补出活塞头或扩大蓝图范围；放置后的红石响应仍遵循游戏机制。
- 盆栽消耗花盆 + 植物；蜡烛蛋糕消耗蛋糕 + 蜡烛；填充炼药锅消耗锅和相应流体材料。
- 有任何水（含 waterlogged）固定需要 **2 个水桶**，没有水不收费；waterlogged 不另加桶数。
- 上升和下降气泡柱保留原始状态，随水一起放置，只参与水材料计费；底部的灵魂沙或岩浆块正常计费。
- 每个岩浆源需要 **1 个岩浆桶**；流动岩浆不另收费。
- 消耗水桶、岩浆桶或细雪桶后立即返还空桶，优先右侧 **3×3 容器返还区**，先合并已有同类物品再使用空格，九格均无法容纳时转入背包或工程台旁掉落。返还区支持取出和 Shift-click，不接受手动投入材料。
- 潜影盒内的材料按相同规则消耗，支持材料替代及盒内流体桶返桶。使用后返还原盒，未用完和不匹配的材料保留原槽位，盒子的颜色、名称等组件保留；材料用完则返还空盒。返还顺序与空桶相同。没有可用材料的盒子留在输入槽，已充满时不消耗材料。潜影盒保持每槽一个，不展开嵌套容器。
- 材料输入的数量会完整存档。取出时回到原版堆叠大小：点击取出一组，Shift-click 按原版上限填入背包，背包装不下的材料留在工程台。
- 空气、普通火焰、灵魂火焰不收费；火焰按原始状态粘贴，放置时不检查支撑或额外启动火焰 Tick。
- 实体完全不参与导入、保存、计费或生成。

扩展例子：数据包中的 `data/prefablitematica/tags/item/materials/wooden_planks.json`：

```json
{
  "replace": false,
  "values": ["othermod:custom_planks"]
}
```

把其他模组相同形态的物品加入对应 Tag 即可。多个 Tag 重叠时，导入分类按 `MaterialGroup` 明确的顺序选择；充能只消耗实际满足的数量，不会重复计算。新增不支持的特殊物品形态需要扩展 `BlockMaterialResolver`。
