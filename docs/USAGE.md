# 使用指南

适用于 PrefabLitematica 0.1.0。安装环境见 [项目首页](../README.md)，计费细节见 [材料规则](MATERIALS.md)。

1. 合成蓝图工程台：上排 `铁锭 木板 铁锭`，中排 `木板 工作台 木板`，下排三个木板。
2. 合成空白蓝图：八张纸围绕一个蓝色染料。
3. 将 `.litematic` 原理图放入 Litematica 的原理图目录；也可以使用已存在的投影或已读入的原理图。无需先加载到世界或选中投影。
4. 打开工程台，把**空白蓝图**放入蓝图槽，点击「载入建筑」，从可搜索、翻页的列表选择建筑。支持未启用的投影；导入文件不会创建、启用或选中世界投影。导入期间保持 GUI 打开、蓝图槽不变。成功后物品自动变为带名称、尺寸及独立蓝色图标的**已加载蓝图**。
5. 将材料放入左侧 **3×3 输入区**，点击「开始充能」。同种物品可在同一槽累加，先投入 64 个石头再投入 64 个，该槽显示 128 个；每槽最多 **4096**。普通放入和 Shift-click 都支持合并，槽满时 Shift-click 转入其他材料槽。也可直接放入装有材料的**潜影盒**。可以分批充能，未使用的材料保留。右侧材料列表显示物品图标、接受的大类、投入数量和剩余数量；缺少的材料排在前面，已满足的材料排在后面并显示为灰色，充能后重新排序并返回第一页。排序覆盖整份列表，再进行分页。
6. 或在同一个 **3×3 材料输入区**放入一个**创造蓝图充能电池**，点击充能。电池优先消耗一个，立即完成全部需求，不消耗其他材料、不产生空桶。没有独立电池槽。
7. 取出充满的蓝图，右击方块的某个面，在该面的相邻格作为建筑 Origin 放置。潜行右击循环切换 0° / 90° / 180° / 270°。
8. 默认保留蓝图物品，完成建筑后将共享充能归零；再次使用需重新充能。

创造电池只在创造物品栏中提供，也可以用管理员命令获得：

```mcfunction
/give @s prefablitematica:creative_charge_battery
/give @s prefablitematica:blank_blueprint
/give @s prefablitematica:workbench
```

**电池没有合成配方、战利品、交易或世界生成来源**。管理员给予生存玩家的电池也可以使用；控制来自其创造/管理员获取渠道。

空白蓝图使用 `prefablitematica:blank_blueprint`，可合成并在创造栏获得。已加载蓝图使用 `prefablitematica:blueprint`，只在成功导入后生成；「已加载」表示已保存建筑数据，仍需达到 100% 充能才能放置。
